Проект инженерно готов, но как открытый — нет. Проверено 2026-07-28:

| Факт | Состояние |
|---|---|
| `github.com/puddingtonnn/gmp-model` | 404 — репозиторий приватный |

| `module gmp-model` | не путь импорта: ломает конвенцию Go, `go get`, pkg.go.dev |

| CONTRIBUTING / CoC / SECURITY / шаблоны issue | отсутствуют |
| Атрибуция гофера, шрифтов, floor796 | отсутствует (LICENSE Apache-2.0 есть) |

При этом суть в порядке: `go test ./...` — 5/5 пакетов зелёные, `vitest` — 139/139,
кросс-сборка под Windows проходит, 0 TODO/FIXME в коде, все пакеты `internal/*`
имеют doc-комментарии, `.gitignore` аккуратный (91 tracked-файл, мусора нет).

**Разрыв — в упаковке, не в существе.** Оценка «как увидит зашедший сегодня» —
5.0/10; после упаковки — ~8.4/10, и почти вся дельта чинится за 1–2 дня.

## Цель

Две одновременно, они задают разный приоритет и обе обязательны:

- **Учебный артефакт** — точность, статья-запуск, стабильный URL демо.
- **Живой OSS-проект** — CI, онбординг, шаблоны, good-first-issue.

## Имя (решено)

`gmp-model` → **`go-scheduler-live`**, модуль `github.com/puddingtonnn/go-scheduler-live`.

Причины: люди ищут «go scheduler visualization» — имя должно попадать в запрос;
`GMP` в поиске отдаёт GNU Multiple Precision; слово «model» прямо противоречит
главному тезису проекта («это не симуляция»). Обаяние (гоферы, цех) остаётся в
заголовке README и на сайте, где оно и работает.

Цена переименования сейчас минимальна и дальше только растёт: **9 Go-файлов** с
импортами, 2 комментария в `cmd/server/main.go`, константа `workloadPkg`
(`internal/tracerun/runner.go:20`), `VITE_BASE` в `.github/workflows/pages.yml:38`,
комментарий в `web/vite.config.ts`.

## Решение — пять фаз

Каждая следующая бессмысленна без предыдущей.

### Фаза 0 — гигиена (блокирует всё)

1. `dev` → `main` fast-forward (`main` на 0 коммитов впереди).
2. Переименование модуля и репозитория; обновить `workloadPkg` и `VITE_BASE`.
3. Блок **Credits** в README + файл `NOTICE` (конвенция Apache-2.0): гофер —
   CC BY 3.0, Renée French; шрифты Pixelify Sans и JetBrains Mono — OFL;
   floor796 — влияние на зум/пан и визуальный язык.
4. Свежий скриншот v3 + GIF. Текущий `docs/screenshot.png` снят до фабричного
   редизайна: на нём `<select>` вместо чипов сценариев, тонкий прогресс-бар
   вместо таймлайн-канваса, нет цеха — то есть UI, которого больше нет.
5. `docs/superpowers/specs/` → `docs/design/` (путь протекает названием тулинга).
6. `CLAUDE.md` не удалять, а **конвертировать**: архитектурная часть переносится
   в `docs/architecture.md` для людей, в `CLAUDE.md` остаётся тонкая ссылка.

### Фаза 1 — демо (блокирует запуск)

Репозиторий публичный → Pages включаются бесплатно → воркфлоу отрабатывает
впервые. Проверить `VITE_BASE` под новое имя, убедиться, что запечённая матрица
грузится, вынести ссылку на демо **первой строкой README**.

Визуализатор, который нельзя посмотреть за один клик, не обсуждают. До этой
фазы анонсировать нечего.

### Фаза 2 — гейты качества

Воркфлоу `ci.yml` на PR и push: `go vet` + `go test ./...` + `tsc --noEmit` +
`vitest run`; отдельным job — Playwright-контракт контролов. Плюс
`golangci-lint`, `dependabot`, починенные бейджи (текущий ведёт на `pages.yml`,
который ни разу не проходил).

Всё это уже зелёное локально — не хватает только доказательства снаружи.

### Фаза 3 — контрибьюторская поверхность

Архитектура уже даёт **три готовых контрибьюторских интерфейса**; CONTRIBUTING
строится вокруг них, а не вокруг общих слов:

| Интерфейс | Почему дёшев в ревью | Что даёт |
|---|---|---|
| **Сценарий** — один файл в `internal/scenarios/`, `Register` в `init()`, свой тест | полностью изолирован, границы пакетов уже разведены | бесконечный генератор good-first-issue: context-отмена, worker pool, `select` с таймаутом, atomic vs mutex |
| **Язык** — один словарь в `web/src/i18n.ts` | паритет проверяет **компилятор** (`typeof RU`), пропуск строки не соберётся | редкий случай честно лёгкого вклада |
| **Отчёт о достоверности** — тип issue «мир показывает X, рантайм делает Y» | ответ = ссылка на трейс или правка панели допущений | прямо обслуживает учебную цель; превращает скептика в контрибьютора |

Файлы: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant),
`SECURITY.md`, шаблоны issue (bug / scenario / fidelity) и PR. Роадмап — **секция
в README**, не отдельный файл: отдельный `ROADMAP.md` на проекте такого размера
устаревает быстрее, чем читается.

`SECURITY.md` здесь не формальность: `internal/tracerun/runner.go:49` вызывает
`go run` **на каждый запрос**. Значит бэкенд требует Go-тулчейн и дерево
исходников в рантайме, а публично выставленный сервер — это компиляция по
требованию от анонимов. Для локального учебного инструмента нормально; должно
быть проговорено явно.

### Фаза 4 — учебный слой

Тег `v0.1.0` + релиз, статья («как вытащить реальный планировщик Go из
`runtime/trace`»), и только потом анонс. Тезис поста — **«это не симуляция»**;
именно он выдерживает критику на r/golang, гоферы — нет.

## Раскрытие AI-ассистированности (решение)

Закоммиченный `CLAUDE.md`, путь `docs/superpowers/` и темп коммитов делают
ассистированную разработку очевидной для любого, кто посмотрит внимательно.
Решение: **сказать самому, одной строкой в README** — разработано в паре с
Claude Code, каждое утверждение о рантайме подтверждено тестами и трейсом.
Быть открытым дешевле, чем быть пойманным, и это снимает главный вопрос
заранее, вместо того чтобы отвечать на него в комментариях после запуска.

## Настоящие дефекты, которые чинятся по пути

- **Windows: пять сценариев вместо шести.** `internal/scenarios/syscalls.go`
  под `//go:build unix`, README обещает «шесть», UI об этом не сообщает. Либо
  оговорка в README, либо явное сообщение в интерфейсе.
- **Устаревший скриншот** (см. Фаза 0.4).
- **Расхождение в числе контрольных точек** между README и текущим
  `verify-controls.mjs` — README писался до v3.

## Верификация

- `go build ./...`, `go vet ./...`, `go test ./...` — зелёные после переименования.
- `go run ./cmd/server` + `npm run dev` из чистого клона: сценарий отрабатывает
  end-to-end, то есть `workloadPkg` с новым путём резолвится в **локальный**
  модуль, а не в сетевую загрузку.
- `GOOS=windows go build ./...` — проходит.
- CI зелёный на тестовом PR.
- Демо отдаёт 200 и проигрывает запечённый прогон.
- Все ссылки README живые (демо, бейджи, credits).

## Вне скоупа (осознанно)

- Вынос `traceparse`/`timeline` в отдельную библиотеку. Заманчиво — это дало бы
  вторую, не-игрушечную аудиторию, — но это отдельный проект и решение после
  запуска, по спросу.
- Docs-сайт: README справляется.
- Погоня за покрытием; новые сценарии сверх существующих шести; новые языки
  сверх RU/EN (это работа контрибьюторов — в том и смысл Фазы 3).
- Предсборка бинаря workload вместо `go run` на запрос — не блокер запуска,
  заводится как good-first-issue.
- Разбиение `web/src/scene/scene.ts` (746 строк) — туда же.
